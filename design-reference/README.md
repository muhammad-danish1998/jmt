# design-reference

Static HTML exports of the approved JMT design (desktop and mobile). They are the visual and copy reference for the redesign.

- Open any file in a browser to see the screen. Desktop files are designed for a 1440px wide window, mobile files for 390px.
- Colors, spacing and copy in these files are final unless AGENTS.md says otherwise.
- `deferred/` holds the Google reviews section. Do not build it yet.
- These files are mockups. Do not copy their markup blindly: rebuild each section as React components using the existing project's patterns, keeping the same copy, spacing and styles.
- `assets/jmt-logo.png` is the real logo (transparent background). `assets/director.jpg` is a low-resolution crop for layout only. Ask the owner for the original photo.
